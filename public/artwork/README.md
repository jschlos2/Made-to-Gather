# Event artwork

Place optimized, replaceable event artwork in this directory.

- `graduation-poster.jpg` is the approved graduation artwork.
- `birthday-balloons.png` is safe placeholder artwork for Theo’s first birthday.
- Export Theo’s final Illustrator or Figma art as an optimized PNG, WebP, or SVG here, then update `artwork.src`, `width`, `height`, and `alt` in `src/data/events.ts`. Keep invitation text out of flattened artwork whenever it should remain selectable.
